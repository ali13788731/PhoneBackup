# Phone Backup (v2)

برنامه‌ی پشتیبان‌گیری و بازیابی **مخاطبین، تماس‌ها و پیامک‌ها** — Kotlin + Jetpack Compose، فارسی و راست‌به‌چپ، با فونت وزیرمتن و تاریخ شمسی.
طراحی شده توسط **Mr.PC**.

## امکانات
- اسپلش انیمیشنی: لوگو خودش را می‌کشد و زیرش «طراحی شده توسط Mr.PC» ظاهر می‌شود.
- مخاطبین، تماس‌ها و پیامک‌ها **سه بخش کاملاً جدا** هستند (هر کدام لیست، جستجو، انتخاب و خروجی خودش را دارد).
- «انتخاب همه» (پیش‌فرض روشن). در تماس‌ها و پیامک‌ها فیلتر: **همه / دارای سابقه / بدون سابقه (صفر)**.
- تاریخ هر مخاطب (آخرین ویرایش) خوانده، نمایش و در فایل پشتیبان ذخیره می‌شود؛ تاریخ هر تماس و پیامک هم همین‌طور.
- نوار پیشرفت انیمیشنی برای خروجی و بازیابی، با صفحه‌ی نتیجه.
- بازیابی انتخابی (می‌توانید فقط مخاطبین یا فقط تماس‌ها … را برگردانید) و رد کردن موارد تکراری.
- خروجی مخاطبین به‌صورت JSON یا VCF؛ صفحه‌ی «پشتیبان‌های ذخیره‌شده» (بازیابی/ارسال/حذف).
- تنظیمات: تم (خودکار/روشن/تیره)، ۴ رنگ، انیمیشن، لرزش، فرمت خروجی، رد تکراری‌ها.

## رفتار نسخه‌ی رایگان
- امکانات پولی نمایش داده می‌شوند ولی **کم‌رنگ و قفل‌اند** (لمس ← صفحه‌ی خرید).
- در مخاطبین/تماس‌ها/پیامک‌ها، جزئیات **مورد اول** رایگان باز است و بقیه قفل (تا کاربر بفهمد پریمیوم به چه دردی می‌خورد).
- لیبل **FREE/PRO** بالا سمت چپ: FREE ← صفحه‌ی پلن و اشتراک؛ PRO ← صفحه‌ی «تاریخچه‌ی اشتراک».
- فیلتر «همه / دارای سابقه / بدون سابقه» حذف شد.

## پلن‌ها (کافه‌بازار)
| | رایگان | پریمیوم (۲۰۰ هزار تومان) |
|---|---|---|
| خروجی **همه‌ی** مخاطبین، یا تماس‌ها، یا پیامک‌ها (هر بخش جدا) | ✓ (Download/PhoneBackupPro) | ✓ |
| **پشتیبان کامل** (هر سه بخش با هم در یک فایل) | ✗ | ✓ |
| بازیابی و فیلتر ساده (همه/دارای سابقه/صفر) | ✓ | ✓ |
| **انتخاب دلخواه** | ✗ | ✓ |
| **جستجو** و **فیلتر پیشرفته** | ✗ | ✓ |
| جزئیات تماس‌ها و متن پیامک‌ها | ✗ (قفل) | ✓ |
| **اشتراک‌گذاری** (بعد از ساخت فایل و در صفحه‌ی بازیابی) و حذف پشتیبان‌ها | ✗ | ✓ |
| ذخیره در **هر مسیر دلخواه** | ✗ | ✓ |

## ساختار صفحه‌ها
- بالا: دکمه‌ی **منو** و لوگوی برنامه (چسبیده به لبه‌ی چپ). پایین: خانه، مخاطبین، تماس‌ها، پیامک‌ها.
- خانه: پشتیبان کامل + بازیابی، و سه بخش جدا.
- منو: پلن و اشتراک (جزئیات خرید از بازار)، بازیابی از فایل (پشتیبان‌های خود برنامه + فایل‌های پیداشده‌ی تلگرام و ...؛ ارسال/حذف برای پریمیوم)، تنظیمات، درباره‌ی ما.

## اعلان‌ها و به‌روزرسانی اجباری
- هر `Config.REMINDER_HOURS` ساعت (پیش‌فرض ۶) برای کاربر بدون اشتراک اعلان معرفی پریمیوم نمایش داده می‌شود (در تنظیمات قابل خاموش شدن است).
- یک فایل JSON روی هاست خودتان بگذارید و آدرسش را در `Config.UPDATE_JSON_URL` قرار دهید:
```json
{"latestVersionCode": 4, "minVersionCode": 3, "latestVersionName": "2.2", "notes": "بهبودها ..."}
```
  اگر `latestVersionCode` از نسخه‌ی نصب‌شده بیشتر باشد اعلان به‌روزرسانی می‌آید؛ اگر `minVersionCode` از نسخه‌ی نصب‌شده بیشتر باشد برنامه قفل می‌شود و فقط صفحه‌ی «به‌روزرسانی اجباری» (لینک بازار) را نشان می‌دهد.

## قبل از انتشار در کافه‌بازار (حتماً)
1. در پنل توسعه‌دهنده‌ی بازار محصول ۲۰۰ هزار تومانی بسازید و شناسه را در `Config.PREMIUM_SKU` بگذارید (خرید یک‌باره؛ `USE_SUBSCRIPTION=false` که الان تنظیم است. اگر اشتراک ماهانه ساختید `true` کنید).
2. کلید RSA را در `Config.BAZAAR_RSA_KEY` بگذارید.
3. `applicationId` اکنون `ir.mrpc.phonebackuppro` است؛ اگر خواستید تغییر دهید (باید با پکیج ثبت‌شده در بازار یکی باشد).
4. `Config.UPDATE_JSON_URL` را تنظیم کنید.
5. امضا: یا Android Studio (Generate Signed Bundle/APK) یا متغیرهای محیطی `KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`؛ در گیت‌هاب Secrets: `KEYSTORE_BASE64` و سه مورد دیگر.
6. تصاویر و متن‌های فروشگاه در پوشه‌ی `store/` است و در هر اجرای گیت‌هاب به‌صورت Artifact با نام `PhoneBackupPro-store-assets` کنار APK دانلود می‌شود.
7. وضعیت پریمیوم فقط بعد از تأیید بازار ذخیره می‌شود و تا ۷ روز بدون اینترنت معتبر می‌ماند.

## دو نسخه (Build Flavor)
| | `free` (نسخه‌ی اصلی / فروشگاه) | `premium` (نسخه‌ی تست پولی) |
|---|---|---|
| شناسه | `ir.mrpc.phonebackuppro` | `ir.mrpc.phonebackuppro.premium` (کنار نسخه‌ی اصلی نصب می‌شود) |
| پریمیوم | قفل تا خرید از بازار | **همه‌ی امکانات باز**، بدون اتصال به بازار |
| داده‌ی نمایشی | ندارد | جزئیات خرید پر + چند فایل پشتیبان نمونه در «بازیابی از فایل» (فقط نمایش؛ بازیابی نمی‌شوند) |

نسخه‌ی `premium` فقط برای دیدن و تست است و نباید در بازار منتشر شود. ساخت: `gradle :app:assembleFreeDebug :app:assemblePremiumDebug`.

## اگر موقع نصب APK گوگل «Play Protect» جلوی نصب را می‌گیرد
برنامه مجوزهای حساس (پیامک، تماس، مدیریت فایل‌ها) دارد و APK دیباگ با کلید دیباگ امضا شده؛ Play Protect روی چنین فایل‌هایی (خارج از فروشگاه) هشدار می‌دهد. راه‌حل: روی «More details / جزئیات» بزنید و «Install anyway / نصب به هر حال»، یا موقتاً Play Store ← پروفایل ← Play Protect ← ⚙ ← «Scan apps with Play Protect» را خاموش کنید. برنامه‌ای که از کافه‌بازار نصب شود این مشکل را ندارد.

## ساخت
Android Studio (JDK 17) یا همان workflow گیت‌هاب (`.github/workflows/build.yml`) که APK دیباگ می‌سازد.
کتابخانه‌ی پرداخت (Poolakey) از JitPack می‌آید و در `settings.gradle.kts` اضافه شده است.

## نکته‌ها
- بازیابی پیامک نیاز دارد برنامه موقتاً «پیش‌فرض پیامک» شود؛ بعدش برنامه راهنمایی می‌کند که برنامه‌ی قبلی را برگردانید.
- گوگل‌پلی دسترسی SMS/Call Log را محدود می‌کند؛ کافه‌بازار ساده‌تر است.
- یک سیاست حریم خصوصی منتشر کنید (برنامه مخاطبین، پیامک و تماس‌ها را می‌خواند؛ هیچ داده‌ای به اینترنت نمی‌فرستد؛ فقط فایل نسخه دریافت می‌شود).
