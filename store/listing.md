# متن‌های معرفی برنامه برای کافه‌بازار / Store Listing

## ───── فارسی ─────

**نام برنامه:** Phone Backup | پشتیبان‌گیری مخاطبین، تماس و پیامک

**توضیح کوتاه (حداکثر ~۸۰ کاراکتر):**
پشتیبان‌گیری و بازیابی سریع مخاطبین، تماس‌ها و پیامک‌ها، با ظاهری زیبا

**توضیح کامل:**
Phone Backup یک برنامه‌ی کامل، سریع و زیبا برای پشتیبان‌گیری و بازیابی «مخاطبین»، «تاریخچه‌ی تماس» و «پیامک‌ها»ست. با یک لمس از همه‌چیز فایل پشتیبان بگیرید و هر زمان خواستید، روی همین گوشی یا گوشی جدید برگردانید.

🎨 ظاهر مدرن و انیمیشنی
• لوگوی متحرک هنگام ورود
• رابط کاملاً فارسی و راست‌به‌چپ با فونت وزیرمتن
• تم تیره/روشن/خودکار و ۴ رنگ اصلی
• تاریخ شمسی و اعداد فارسی
• نوار پیشرفت انیمیشنی برای خروجی و بازیابی

📇 سه بخش کاملاً جدا
• مخاطبین (همراه با تاریخ ثبت/به‌روزرسانی)
• تاریخچه‌ی تماس‌ها
• پیامک‌ها
هر بخش لیست، انتخاب و خروجی مخصوص خودش را دارد.

✅ انتخاب همه (به‌صورت پیش‌فرض فعال)
• فیلتر «همه / دارای سابقه / بدون سابقه (صفر)» برای تماس‌ها و پیامک‌ها
• خروجی JSON و vCard (VCF) برای مخاطبین
• جلوگیری از موارد تکراری هنگام بازیابی

🆓 رایگان، برای همیشه
• پشتیبان‌گیری کامل از همه‌ی مخاطبین، تماس‌ها و پیامک‌ها
• بازیابی فایل پشتیبان
• تنظیمات و شخصی‌سازی

⭐ پریمیوم — فقط ۲۰۰ هزار تومان
• انتخاب دلخواه مخاطبین، تماس‌ها و پیامک‌ها
• جستجو و فیلتر بسیار پیشرفته (تاریخ، نوع تماس، مدت، جهت پیامک، منبع، مرتب‌سازی و …)
• مشاهده‌ی جزئیات تماس‌ها و متن پیامک‌ها
• ذخیره‌ی فایل در هر مسیر دلخواه
• اشتراک‌گذاری و حذف پشتیبان‌های ساخته‌شده، مستقیم از صفحه‌ی «بازیابی از فایل»

🔒 حریم خصوصی
اطلاعات شما فقط روی گوشی شما می‌ماند. برنامه هیچ مخاطب، تماس یا پیامکی را به اینترنت ارسال نمی‌کند (فقط یک فایل کوچک شماره‌ی نسخه برای اعلان به‌روزرسانی دریافت می‌شود).

ℹ️ برای بازیابی پیامک‌ها، اندروید لازم است برنامه را موقتاً «برنامه‌ی پیش‌فرض پیامک» کنید؛ پس از پایان، برنامه‌ی قبلی را برگردانید.

**کلمات کلیدی:** پشتیبان گیری، بکاپ، مخاطبین، پیامک، تماس، بازیابی، انتقال اطلاعات، VCF، مخاطبین گوشی

## ───── English ─────

**App name:** Phone Backup – Contacts, Calls & SMS

**Short description:**
Fast, beautiful backup & restore for your contacts, call log and text messages.

**Full description:**
Phone Backup is a complete, fast and beautiful way to back up and restore your contacts, call history and SMS messages. Save everything to a single file and bring it back on this phone or a new one at any time.

🎨 Modern, animated design
• Animated logo on launch
• Fully right-to-left Persian interface (Vazirmatn font)
• Dark / light / auto theme and 4 accent colors
• Jalali (Persian) calendar dates
• Animated progress ring for export and restore

📇 Three separate sections
• Contacts (with dates)
• Call history
• SMS messages
Each has its own list, selection and export.

✅ Select all (on by default)
• "All / With history / Zero history" filter for calls and SMS
• JSON and vCard (VCF) export for contacts
• Duplicate-skipping on restore

🆓 Free, forever
• Full backup of all contacts, calls and SMS
• Restore from a backup file
• Settings and personalization

⭐ Premium – one small payment (200,000 Toman)
• Pick exactly which items to back up
• Very advanced search & filters (date, call type, duration, SMS direction, source, sorting and more)
• Call details and SMS text preview
• Save the file anywhere you like
• Share or delete your earlier backups right from the Restore screen

🔒 Privacy
Your data stays on your device. No contact, call or message is ever uploaded (the app only fetches a tiny version file to notify you of updates).

ℹ️ To restore SMS, Android requires the app to be temporarily set as the default SMS app; switch back afterwards.

Designed by Mr.PC

**What's new (v2.2):** Menu moved to the top bar, logo docked to the left edge • "Restore from file" and "Saved backups" merged into one screen • Performance and stability improvements

**Keywords:** backup, restore, contacts, SMS, call log, vcf, transfer, Persian
